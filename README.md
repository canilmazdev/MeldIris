# MeldIris

MeldIris is a cloud-based, event-driven trading platform utilizing real-time data processing and scalable cluster architecture management.

MeldIris is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- MeldIris is a cloud-based, event-driven
- trading platform utilizing real-time data
- processing and scalable cluster architecture

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/MeldIris.git`
2. `cd MeldIris`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
